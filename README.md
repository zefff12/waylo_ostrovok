# Waylo — One prompt. Your whole journey.

MVP ИИ-агента для планирования путешествий для трека «О!дин запрос» (Островок).
Пользователь пишет одно сообщение. Агент разбирает запрос, при необходимости предлагает направления, подбирает и сравнивает транспорт и отели, считает бюджет, составляет прогулки по дням с картой, проверяет состыковки, пересобирает план по правкам и доводит пользователя до демо-оформления.

ТЗ с дополнениями под трек лежит в [docs/Waylo_TZ_v2.docx](docs/Waylo_TZ_v2.docx), раздел 19.

**Демо:** https://waylo-cfp5.onrender.com (бесплатный тариф Render: после 15 минут без посещений сервис засыпает, первое открытие занимает около минуты).

## Быстрый запуск

Нужны Python 3.11+ с [uv](https://docs.astral.sh/uv/) и Node.js 18+.

```bash
cp .env.example .env          # ключи необязательны
cd frontend && npm install && npm run build && cd ..
uv run --project backend uvicorn app.main:app --app-dir backend --port 8000
```

Откройте http://localhost:8000 (ключ Яндекс Карт разрешён только для `localhost`; по 127.0.0.1 будет карта OpenStreetMap). Backend сам раздаёт собранный frontend.

Режим разработки с hot reload: в одном терминале запустите backend командой выше, во втором — `npm --prefix frontend run dev`, затем откройте http://localhost:5173 (запросы `/api` проксируются на :8000).

Замер качества агента:

```bash
uv run --project backend python eval/run_eval.py          # офлайн-агент
uv run --project backend python eval/run_eval.py --llm    # нейросеть из WAYLO_LLM, отчёт в eval/results_<провайдер>.md
```

## Деплой на Render

[Dockerfile](Dockerfile) собирает frontend и запускает FastAPI, [render.yaml](render.yaml) описывает бесплатный веб-сервис во Франкфурте. В панели Render: New → Blueprint → репозиторий, затем ввести `GIGACHAT_CREDENTIALS` (без ключа работает офлайн-агент). Сертификат Минцифры для GigaChat лежит в `certs/` и подхватывается сам. Сохранённые поездки хранятся в SQLite во временной папке и сбрасываются при перезапуске.

## Архитектура

```
frontend (React + TS + MapLibre)  ──/api──▶  FastAPI
                                              ├─ agent_tools.py   общие 11 инструментов и системная инструкция
                                              ├─ agent_gigachat.py GigaChat (Сбер), вызов функций
                                              ├─ agent_llm.py     Claude Haiku 5.5, tool calling
                                              ├─ agent_offline.py правила, если ключа нет или Claude недоступен
                                              ├─ data.py, data_extra.py  каталог: 39 направлений, места, вокзалы и аэропорты
                                              ├─ planner.py       операции над поездкой + журнал изменений
                                              │   ├─ destinations.py  вдохновение: климат, цена, время в пути
                                              │   ├─ transport.py     поезд / самолёт, ранжирование
                                              │   ├─ hotels.py        сравнение по цене, месту, отмене, питанию, питомцам, детям
                                              │   ├─ walks.py         места по интересам → дни → маршрут от отеля
                                              │   ├─ budget.py        бюджет из позиций, превышение, способы сэкономить
                                              │   └─ connections.py   прибытие ↔ заселение ↔ трансфер ↔ выезд ↔ отправление
                                              ├─ integrations.py  Open-Meteo, Travelpayouts, 2ГИС, Overpass (таймауты и кэш)
                                              └─ store.py         SQLite: поездки, история диалога, память предпочтений
```

Принцип из ТЗ: LLM понимает запрос, выбирает инструменты и объясняет решения, а все цены, время и проверки считает код. Обе версии агента вызывают одни и те же функции planner, поэтому расчёты у них совпадают.

Нейросеть выбирается переменной `WAYLO_LLM` в `.env`: `gigachat`, `claude`, `offline` или `auto` (первая, для которой задан ключ). Обе нейросети вызывают одни и те же инструменты из `agent_tools.py`, поэтому планы и расчёты совпадают.

### GigaChat (бесплатно)

1. Зарегистрируйтесь в [Studio](https://developers.sber.ru/studio), создайте проект GigaChat API для физлиц и скопируйте **ключ авторизации** в `GIGACHAT_CREDENTIALS`.
2. API GigaChat работает по сертификату Russian Trusted Root CA (Минцифры), которого нет в стандартном хранилище. Сертификат с [gosuslugi.ru/crt](https://www.gosuslugi.ru/crt) уже лежит в `certs/russian_trusted_root_ca.cer`, укажите полный путь к нему в `GIGACHAT_CA_BUNDLE`. Без него запросы падают с ошибкой TLS, и отвечает офлайн-агент, а в чате видна причина.
3. Поставьте `WAYLO_LLM=gigachat` и перезапустите сервер.

Особенности: GigaChat вызывает одну функцию за ход, поэтому сборка поездки занимает несколько запросов подряд. Модель задаётся в `GIGACHAT_MODEL`. По умолчанию стоит `GigaChat-2-Max`: в бесплатном пакете для физлиц на неё выделено около 25 млн токенов. Младшая `GigaChat-2` на живых запросах путала дни с ночами, выдумывала бюджет и не доводила выбор направления до плана; `GigaChat-2-Pro` на запрос «к тёплому морю» предлагала Калининград.

Защита от выдумок модели: город, длительность, даты, бюджет, состав и питомцы, которые парсер нашёл в сообщении, важнее аргументов модели. Город и бюджет, которых пользователь не называл, агент не примет (`agent_tools.begin_turn`). Если «сделай дешевле» ничего не сэкономило, инструмент так и говорит модели.

### Claude

По умолчанию агент работает на **Claude Haiku 5.5** (`claude-haiku-5-5`): $0,10 / $0,50 за 1 млн входных / выходных токенов, примерно в 40 раз дешевле Opus 5.5. Модель меняется переменной `WAYLO_MODEL` в `.env`, например `claude-opus-5-5` для защиты. Adaptive thinking включено по умолчанию, глубина рассуждений задаётся `WAYLO_EFFORT` (по умолчанию `medium`). У Haiku нет автоматического перезапуска на резервной модели при отказе, поэтому отказ обрабатывается в коде. Для Opus 5.5 такой перезапуск (`fallbacks: "default"`) включается сам. Если API недоступен, отвечает офлайн-агент, и в чате это помечено.

## Дизайн: Living Liquid Glass

Интерфейс собран по двум ТЗ на редизайн (Liquid Glass, референсы — в Figma): живое видео путешествий под тонкими стеклянными слоями.

- **Заставка и онбординг** (`components/Intro.tsx`): при первом запуске — проявление оригинального логотипа, проход света и мягкий переход к трём экранам онбординга (что это, что умеет, с чего начать), которые можно пропустить. Повторно — кнопка «Как это работает» или `http://localhost:8000/?intro` (`?intro=hold` держит заставку до клика — для презентации).
- **Фон главного экрана — видео с YouTube** из `WAYLO_HOME_VIDEO` (`components/YouTubeLayer.tsx`). Встраивается официальным плеером youtube-nocookie без звука и элементов управления, растянут как cover; слой проявляется, только когда видео реально играет. Скрипт `iframe_api` с www.youtube.com не используется — в некоторых сетях этот домен недоступен. Пока видео грузится, при ошибке или через 15 с без воспроизведения остаётся локальное видео. Качество выбирает YouTube (в тесте — hd1080).
- **Сцены поездки:** море (морские направления), дождь (если по прогнозу дождливо больше половины дней), пшеничное и закатное поле — локальные ролики 1,2–7 МБ с постерами; кнопка паузы, при `prefers-reduced-motion` — только постер.
- **Стекло:** 4 уровня — Light (навигация), Floating (поиск, нижнее меню), Modal (чат, фильтры, онбординг), Subtle (второстепенное) — с едиными токенами; без поддержки `backdrop-filter` поверхности становятся плотнее. Белая вуаль на экране поездки лёгкая: читаемость дают светлые карточки и стеклянные заголовки разделов, а не заливка экрана.
- **Типографика и движение:** шкала из 7 размеров, одна кривая анимаций и три длительности (`--d1/--d2/--d3`).
- **Без эмодзи:** собственные SVG-иконки (`components/Icons.tsx`); ответы агента без эмодзи — запрет в инструкции LLM, очистка на сервере (`main.strip_emoji`) и при показе.
- **Экраны:** главный (поиск с очисткой, быстрый старт, карусель направлений, примеры), поездка (сводка с цифрами, состыковки, дорога, отели с фильтрами и избранным, бюджет, история), прогулки, оформление в три шага с понятными ошибками формы; состояния загрузки, пустого результата и ошибки.
- **Мобильная версия:** нижняя стеклянная навигация, чат выезжает снизу, онбординг — нижней панелью, учтены safe areas.

## Какие данные реальные

Бейдж у каждой цены и факта в интерфейсе показывает её тип; источник виден при наведении.

| Данные | Источник | Тип |
|---|---|---|
| Прогноз погоды (до 16 дней) | Open-Meteo Forecast | реальные |
| Погода на более дальние даты | Open-Meteo Archive: те же даты прошлого года | оценка, «не прогноз» |
| Климат месяца для выбора направления | Open-Meteo Archive, один пакетный запрос | реальные (архив) |
| Цены перелётов | Travelpayouts / Aviasales Data API (`TRAVELPAYOUTS_TOKEN`) | оценка: кэш поисков, наличие не гарантировано |
| Перелёты без токена, поезда | расчёт по расстоянию | демо |
| Отели: название, тип, звёзды, адрес, координаты, сайт | OpenStreetMap, выгрузка в `backend/app/hotels_osm.json` (~60 на город, обновление: `backend/scripts/fetch_hotels.py`) | реальные |
| Цена отеля за ночь | уровень цен города × звёзды × удалённость × сезон | оценка |
| Отмена, питание, рейтинг, дети, животные в отеле | в OSM не публикуются | демо (животные — реальные, если отмечены в OSM) |
| Места для прогулок | локальный набор: ~300 реальных мест в 39 направлениях, координаты приблизительные | названия реальные, часы не подтверждены |
| Кафе рядом | 2ГИС Places API (`DGIS_API_KEY`) или OSM Overpass | реальные; при недоступности не добавляются |
| Питание, билеты, такси, транспорт по городу | средние ставки по городу | оценка |
| Карта | Яндекс Карты, JavaScript API 3.0 (`YANDEX_JS_API_KEY`, открывать через http://localhost:8000); иначе OpenStreetMap через MapLibre GL | реальные |
| Адреса отелей, которых нет в OSM | Яндекс Геокодер по координатам, при выгрузке (`fetch_hotels.py --geocode`) | реальные |
| Оплата и бронирование | — | только имитация, номер `WAYLO-DEMO-…` |

## Что умеет (сценарии жюри)

- **Один запрос → план.** Агент извлекает город, даты, длительность, состав, детей, питомцев, бюджет, интересы и ограничения. Если чего-то не хватает, берёт допущение и показывает его, а не устраивает анкету.
- **Город не задан** («к тёплому морю в ноябре, недорого, с ребёнком, без долгих перелётов»): 2–3 направления с климатом по архиву, ценой и временем в пути, у каждого есть «почему», «чем жертвуем» и «риски».
- **Сравнение отелей** по цене, расстоянию до мест прогулок, условиям отмены, питанию, рейтингу, допуску животных и детей. Жёсткие ограничения отсекают неподходящие варианты.
- **Проверка состыковок.** Если приехали раньше заселения, агент предложит ранний заезд. Также проверяются ночное прибытие, вечерний отъезд, даты, питомец в транспорте и отеле, выходные дни музеев. При критичной проблеме оформление блокируется.
- **Пересборка без поиска с нуля:** «на два дня позже», «бюджет 35000», «сделай дешевле», «с нами едет собака», «поменяй отель на подешевле», «на поезде». Каждое изменение записывается в журнал с разницей по дням и бюджету.
- **Персональные прогулки.** Места подбираются по интересам с учётом окна дня, обеда, расстояний и пеших переходов или транспорта; на карте показан маршрут от отеля. Правки дня: «меньше ходьбы», «дождь», «заменить на кафе», «добавить музей», «убрать точку».
- **Оформление и после покупки:** сводка корзины, демо-заказ, после него — запрос раннего заезда и трансфера (демо).
- **Память.** Интересы, питомец, дети и город отправления запоминаются между сессиями: идентификатор пользователя хранится в браузере, профиль — в SQLite.
- **Прозрачность.** Кнопка «Что сделал агент» показывает, какие инструменты вызывались и что вернули.

## Результаты проверки

`eval/run_eval.py` прогоняет 28 тестовых запросов (результаты сохраняются в [eval/results.md](eval/results.md)). С офлайн-агентом:

- проверки пройдены: 28/28;
- до плана или корзины доведено: 23/23 сценария, где это ожидается;
- среднее число уточнений: 0,12 (вопрос задаётся только на пустой или бессмысленный запрос и на город вне каталога);
- медиана времени до первой рекомендации: около 0,35 с офлайн и около 7 с на GigaChat-2-Max;
- ответов из резервного офлайн-агента на GigaChat: 0;
- критичных ошибок состыковок: 1 — Калининград с собакой. Туда в демо только самолёт, поэтому агент честно блокирует оформление и предлагает уточнить правила авиакомпании. Это ожидаемое поведение.

Вручную в браузере проверены: запрос по Петербургу из ТЗ, правка дня 2, карта, направление «к морю» → выбор карточки → оформление → демо-заказ, мобильная ширина 375 px.

## Известные ограничения

- В каталоге 39 направлений: 23 в России (от Калининграда до Владивостока, Байкал, Карелия, Мурманск, Кавказ, Золотое кольцо) и 16 за рубежом (Армения, Грузия, Азербайджан, Беларусь, Узбекистан, Сербия, Турция, Египет, ОАЭ, Таиланд, Бали, Гоа, Вьетнам, Китай). Про другие города агент честно говорит, что их нет в демо. Ростов, Краснодар, Анапа и Симферополь не включены: их аэропорты закрыты.
- Набор из 24 кейсов на GigaChat-2-Max ([eval/results_gigachat.md](eval/results_gigachat.md)) прогонялся до расширения каталога.
- Отели реальные, но их цены — оценка, а условия отмены, питание и рейтинг — демо: открытого API Островка с ценами и наличием нет. Цены поездов синтетические (нет открытого API РЖД). Цены перелётов реальные только при заданном токене Travelpayouts.
- Часы работы мест не проверяются, у платных мест стоит пометка «проверьте на сайте». Выходные дни музеев указаны приблизительно.
- Публичный Overpass бывает недоступен или отвечает медленно. Ожидание ограничено 4 секундами, после чего используется локальный набор мест.
- Агент на Claude не проверялся вживую: нет ключа. Агент на GigaChat проверен на реальном API (26.10.2026).

## Что улучшить после MVP

1. Цены, наличие и условия отмены отелей через партнёрский API ETG/Островка (отели уже реальные), поезда через партнёрский API РЖД.
2. Маршруты по улицам: 2ГИС Routing или OpenRouteService вместо расчёта по прямой с поправочным коэффициентом.
   Яндекс «API Поиска по организациям» дал бы часы работы и рейтинги мест, но бесплатно у него только пробный период 7 дней (100 запросов в сутки), дальше от 195 000 ₽ в год.
3. Часы работы мест из 2ГИС с отметкой «подтверждено».
4. Потоковая передача ответа Claude с показом вызовов инструментов в реальном времени.
5. Telegram-бот поверх того же API.
6. Расширенный набор тестов для режима `--llm` и сравнение моделей и уровней effort.
